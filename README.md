# Behavioral Biometrics

## About the Project

Behavioral Biometrics is a project that analyzes user behavioral patterns to help identify or authenticate users based on the way they interact with a system.

## Technologies Used

- HTML
- JavaScript
- Node.js
- JSON

## Features

- User behavior analysis
- Behavioral pattern detection
- Simple web interface
- User authentication/identification concept
